## 👋 About

Senior-level game programmer specializing in **Unity** and **C#**, working across the full development cycle — from gameplay and systems implementation to stabilization, porting, and post-launch maintenance.

My profile combines three core areas:

- 🎮 **Technical game development** — gameplay, systems, tools, and UI.
- 🕹️ **Multiplatform engineering** — porting and platform integration for PC and consoles.
- 🔧 **Production problem-solving** — debugging, QA, certification, and optimization.

I bridge the gap between design intent and stable, shippable features — investigating issues directly inside the project, reproducing and fixing them at the source.
